# Поздравление для Ники

Сайт: https://deniszhi1.github.io/HappyBirthdayNikka/

Локальный сайт: пять шуточных капч, анимированный подарок и двусторонняя открытка в CSS 3D. Работает без сборки и сторонних библиотек. Изображение открытки — предоставленный пользователем оригинал.

## Запуск

Из папки проекта выполните `node server.cjs` и откройте http://localhost:4173.

## Управление

Капчи: галочка → котики (верхний левый, средний правый, нижний средний) → ползунок около 70% → «тортик» → свечи 2, 4, 1, 3.

В финале нажмите «Открыть подарок». Открытка вращается мышью или пальцем. При фокусе на открытке работают стрелки клавиатуры; Home возвращает исходный ракурс. Можно перевернуть, сохранить изображение и повторить раскрытие подарка.

Тексты находятся в index.html и app.js, оформление — в style.css. Открытка — assets/birthday-card.png. Перезагрузка страницы начинает квест заново. Ответы на игровые капчи обрабатываются в браузере и не отправляются на сервер.

## Публикация

GitHub Pages публикует сайт из корня ветки main. Сборка и сторонние зависимости не нужны. Файл .nojekyll отключает обработку Jekyll.
